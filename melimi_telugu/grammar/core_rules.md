# Melimi Telugu Core Grammar Subject

This file is a compact seed of the user's established Melimi derivational system.
The full authoritative corpus should be placed in this folder.

## Productive/recognized formation material

- కాను: agent/doer or characterizing formation; examples include ముప్పుకాను,
  పాటకాను, పెంపుకాను, పాటుకాను.
- వాను: having/related-to formation; examples include నెనరువాను, ప్రాయివాను,
  మైవాను, గెలువాను.
- మారి: quality/characteristic formation.
- అలవి / అర్ది: quality/state families.
- పాదు / పఱ, ద / ఇద, అ, అంగి, మాలు, కము / ఇకము, గము, ఓరు, ఆది, ఓలి, ఓజ:
  recognized derivational families in the supplied Melimi corpus.
- Word formation must follow the actual corpus/rules; suffix presence alone does
  not make every arbitrary combination valid.

## Language policy

Melimi should favor native Telugu expression and established Melimi forms. A
missing equivalent must not be fabricated merely for purity.
