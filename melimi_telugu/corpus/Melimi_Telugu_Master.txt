# Melimi Telugu Project — Transfer Notes

## Purpose

The project is to develop a Telugu language AI system focused on **మెలిమి తెలుగు (Melimi Telugu)**: Telugu developed/expressed primarily from its own linguistic base and resources.

The user distinguishes this from **మిశ్రమ తెలుగు (Mixed Telugu)**: contemporary Telugu containing substantial loan vocabulary from Sanskrit, English, Urdu, Hindi, and other languages.

The intended system is not merely a "pure Telugu chatbot". It is a computational Telugu language-development / register engine that can:
- understand Melimi Telugu
- generate Melimi Telugu
- distinguish Melimi Telugu and Mixed Telugu
- develop modern terminology using Telugu resources
- validate vocabulary and grammar
- convert Mixed Telugu toward Melimi Telugu
- eventually support chatbot, writing, translation, terminology, grammar-checking and research applications

## Technology

- Python

- Groq API for LLM inference
- PostgreSQL
- pgvector initially for vector/RAG functionality
- GitHub

The Groq integration should be isolated behind an LLM abstraction so the linguistic engine is not tightly coupled to Groq.

## Architectural principle

The user's Melimi Telugu corpus and linguistic rules are the authority. Groq is the generation engine, not the linguistic authority.

Conceptual flow:

User
 -> FastAPI
 -> Telugu Register / Language Engine
 -> vocabulary + grammar + terminology + RAG
 -> prompt builder
 -> Groq
 -> Telugu validator
 -> correction if needed
 -> response

The system should not simply put all notes into a prompt and hope the model remembers them.

## Knowledge model principles

Do not treat the knowledge base as only "Mixed word -> Melimi word".

Important categories include:
- native vocabulary
- native-derived vocabulary
- established loans
- acceptable loans
- discouraged loans
- unnecessary loans
- register-specific exclusions
- roots
- derivational patterns
- compounds
- grammar rules
- terminology
- semantic relationships
- examples
- etymology
- source/provenance

Potential vocabulary statuses:
- PREFERRED
- RECOMMENDED
- ACCEPTABLE
- NEUTRAL
- DISCOURAGED
- FORBIDDEN

Important metadata:
- source
- confidence
- register
- domain
- status
- root
- derivation
- examples
- preferred alternative

Important distinction:
- FACT
- OBSERVATION
- PREFERENCE
- NORMATIVE RULE
- PROPOSED RULE
- EXPERIMENTAL TERM
- EXCEPTION

Do not silently turn an author's claim into an established linguistic fact.

## Registers

The project should model registers separately from the language itself.

Potential registers:
- Melimi Telugu
- Mixed Telugu
- formal
- literary
- conversational
- academic
- technical
- Telugu-first modern register

Melimi Telugu should not be defined merely as "remove every non-Telugu word". The intended goal is to expand Telugu's ability to express modern concepts from its own linguistic resources while maintaining intelligibility, naturalness, continuity, grammatical integrity, and productive word formation.

## Terminology development

A central feature should eventually be a terminology-development engine.

Conceptual flow:

new concept
 -> semantic decomposition
 -> find Telugu concepts/roots
 -> apply Telugu derivational and compound patterns
 -> generate candidate terms
 -> validate meaning/grammar/naturalness
 -> rank candidates
 -> human/linguistic evaluation
 -> approved terminology enters knowledge base

Potential terminology laboratory API:
POST /api/v1/terminology

The system should support human approval/rejection of candidate terminology.

## Evaluation

A validator/evaluator should score generated output for:
- native vocabulary use
- native-derived terminology
- grammar conformity
- register conformity
- unnecessary borrowing
- code switching
- semantic correctness
- naturalness

Do not invent a final scoring formula before the linguistic specification is established.

ఒలవును మార్చుటకు చదువు అనేది కడు బ్రోంవాను కైదువు. ఇది వేదార ఎదుగుదలకు ప్రెంపుదలకు అక్కఱ ఎఱుకను, నేర్పులను మనకు అందిస్తుంది. చదువు గుండా ఒక వేదారు తప్పు ఒప్పుల నడుమ తేడాను తెలుసుకుంటూనే దీమసాన్ని పొందుతారు. నాడుప్రెంపుకు, కూటపు ఎగఁదేర్పుకు చదువే నిక్కడ. అందుకే, మంచి రాగడను కట్టుకొనుటకు అందరికీ నాణ్యమైన చదువందే తారిమి ఉండాలి.

కలివిడి తెలుగు:
ప్రపంచాన్ని మార్చడానికి విద్య అనేది అత్యంత శక్తివంతమైన ఆయుధం. ఇది వ్యక్తిగత ఎదుగుదల మరియు అభివృద్ధికి అవసరమైన జ్ఞానాన్ని, నైపుణ్యాలను మనకు అందిస్తుంది. విద్య ద్వారా ఒక వ్యక్తి తప్పు ఒప్పుల మధ్య తేడాను తెలుసుకుంటూనే ఆత్మవిశ్వాసాన్ని పొందుతాడు. దేశాభివృద్ధిలో మరియు సమాజ ఉద్ధరణలో విద్య కీలక పాత్ర పోషిస్తుంది. అందుకే, మెరుగైన భవిష్యత్తును నిర్మించుకోవడానికి ప్రతి ఒక్కరికీ నాణ్యమైన విద్యను పొందే హక్కు ఉండాలి.

## 6. రావాకువలు (రాజులకథలు) — 1

వాకువ పేరు: పరిదొర (జనప్రభు/రాజు)

తుకాటకారులో గంగేరుప్రోలు అనే నేలపాయ ఉండేది. చూసినంతలా పచ్చతనపు పెద్ద పంటనేల, అందమైన పూల్దొడిగిన మడుఁగులు, ఆడుతుపాడుతున్న మంది, పొంగిపొరలుతున్న అలరాటములు.
ఈ గర్గలనేలనేలిన పేరిమిపాదు పెద్దదొరలు, వారి ముందొరలు తేఁకువరులు, నికవల్కరులు, కనికారులు, తరతరాల మన్యంలో సాటిఁడివారు, పోరులో ఓటమిఁడివారు, పేరులో కడిఁడివారు, మందిలో పగఱిఁడివారు. తండ్రిబాటలో నడిచిన కొడుకుకు యేండ్లుగడుస్తున్నాయి ఒక మంచినాడు చూసి రాజలకంతో మన్యమోపికలియ్యాలని ప్రెగడతో అంటాడు. ముందు అరయికగా పరిలోకి తిరుగులకు పంపుతాడు.
చిన్నదొర తిరుగులకు బయల్దేరుతాడు. త్రోవలో పేద తిరిపవాడొకడు అరుగుపైపడి కనిపించగా అతనికి వాదోడుగా "నువొకరిని ఒకటి అడిగే ముందు వారికి ఒకటి ఇవ్వాలి, అప్పుడే ఇయ్యడం తీసుకోవడం సరిపోయి నీకు మరల మరల అంకిలిపడక తిరిపాలు ఇస్తారు" అని ఒక రుక్కరాసిస్తాడు. అతను మేలుకున్నాక చదివి, ఇవ్వడానికి ఏమిలేక పొద్దున అరుదైన పూలుకోసి అందరికి పంచుతూ తిర్పమెత్తగా ఇంటికి కొందరు, గుడికి కొందరు, బడికి కొందరు అందంగించడానికి పనికొస్తాయని అలరాటముగా పూలుతీసుకొని అతనికి తిండిపెడతారు. అతను ఇక నానాట పులుతెచ్చిస్తూ తిరిపమెత్తుకోసాగాడు.
ఈ మంచితలపును పారఁజూసిన పెద్దదొర ఎంతో పొంగిపోతాడు, జాగుచేయక రాజలకంతో పరిదొరను చేసారు, చిన్నదొర ప్రోలును ముందటులవలె మంచిగా యేలుతాడు. గంగేరుప్రోలు వెలుగొందింది.

## 9. Foundational-source note

బంగారు నాణేలు (1st edition) is the foundational historical grammar source identified by the user. It is described as the first book introducing Melimi Telugu/native-Telugu-based register.

The full 1st-edition grammar supplied by the user is preserved in the conversation corpus and should be treated as the historical baseline. It includes:

కరఁగు + కల్లు→ కరకల్లు (కరఁగెడి తాయి లోహము)
చిచ్చు (నిప్పు) + క్రోవి (గొట్టము) చిక్రోవి (నిప్పుల గొట్టము తుపాకి) సిక్రోవి.
ప్రొద్దు + పాఱిక ప్రొవ్వాటిక/ ప్రావాఱిక/ ప్రోవాఱిక (సూర్యునకై నీటిని అర్ఘ్యముగా పాటించుట - సంధ్యావందనము)
ఉండు + వలతి→ ఉన్ వలతి = ఉన్వలతి (ఉండెడి చోటు నివాస స్థానము-చిరునామా, address)
మోము + తీరు→ మోదీరు (వైఖరి)
గంగి + నూలు (పవిత్రమైన దారము)గన్నూలు (యజ్ఞోపవీతము)
గంగి + నోలు (పవిత్ర గ్రంథము) గన్నోలు
తిరిగి తిరి = మరల (సంస్కృతములోని 'పునః' కు సమానార్ధకముగా.
బ్రదిమి→ బ్రది, బ్రదీ = బ్రదుకునట్టి, బ్రదికి ఉన్న (live/ alive); మఱియు బ్రదుకునకు సంబంధించిన.
సమయు→ సమ/సమా = చావు, చావునకు సంబంధించిన, చనిపోయిన.
ఉండుదేఱు→ ఉందేఱు = హాజరగు ; ఉందేఱిక = హాజరీ ; ఉందేఱువు = హాజరైన మనిషి : ఉందేఱమి = గైర్హాజరీ.

అరి : తెగువరి, తలవరి, జాలరి, మేదరి, నిజమరి, పోటర్, పూజారి, తలారి

మరికొన్ని లోతుగా :
1. అరి, కాఁడు గాఁడు, కత్తె' లకు మారుగా 'కాను/ కాన్' = చేయునట్టి
ముప్పుకాను (dangerous) = ప్రమాదకరము, ప్రమాదకరములు, ప్రమాదకారి, ప్రమాదకారులు
మచ్చుకలు : వాఁడు ముప్పుకాను. అది ముప్పుకాను. ఆమె ముప్పు కానిత (స్త్రీలకు కాను/కానిత ఏదైనా)
కాను/కాన్ యొక్క భావార్ధకము 'గారము' లేక 'కానికము' ఉదాహరణకు ముప్పుకాను ముప్పుకానికము, ముప్పుగారం (ప్రమాదకరం).

2. 'వాను/ వాన్' : 'కలిగిన సంబంధించిన'
నెనరు = కృతజ్ఞత : నెనరువాను/ నెనర్వాను/ నెనర్వాన్ = కృతజ్ఞుఁడు
ప్రాయి = అదృష్టము : ప్రాయివాను/ ప్రాయివాన్ = అదృష్టవంతుఁడు
నోలు = గ్రంథము : నోలువాను = గ్రాంథికము
మై = శరీరము : మైవాను/ మైవాన్ = భౌతికము (మైవాను ఆకట్టు=భౌతిక ఆకర్షణ)
i. విశేషణ పదములతో వ్యక్తులను, వస్తువులను ఆపాదించుటకు సైతము 'వాను' ఎసవాడవచ్చును. ఉదాహరణకు-
బ్రాక/ బ్రాకము - బలహీనము : బ్రాకవాను = బలహీనుఁడు, బలహీనురాలు, బలహీన వస్తువు.
ii. ఏ విధమైన లింగసూచక ప్రత్యయములు గానీ లేని నామవాచకములకు కూడ స్వార్థకముగా వాను/వాన్ చేర్చవచ్చును. ఉదాహరణకు-
రెంచ = మనిషి : రెంచవాను (అదే, మనిషి)
మాస్టి = శూరుఁడు : మాస్టివాను (అదే, శూరుఁడు)
iii. క్రియాధాతువులకు కూడ వాను/వాన్ చేర్చవచ్చు. అటువంటి సందర్భములలో ఇది 'అరి'కి ప్రత్యామ్నాయమగును. ఉదాహరణకు-
గెలుచు + వాను గెలువాను = గెలుచువాఁడు గెలుచువది (విజేత విజేత్రి)
నిలుచు + వాను నిలువాను = నిలచునది (durable, enduring)
ఏలు + వాను→ ఏలువాను = ఏలెడివాఁడు, ఏలునది (పరిపాలకుఁడు Governor)
iv. కావలెననుకొన్నచో 'వాను/వాన్' కు కూడ స్త్రీలింగప్రత్యయములను చేర్చి లింగ విశిష్టముగా మార్చి ఐతే పుల్లింగ నపుంసక లింగ రూపములలో మటుకు మార్పుండదు. ఉదా :-
వాఁడు మోపికవాను/ మోపికరి (బాధ్యతాయుతుఁడు).
ఈ అమరము మోపికవాను/ మోపికరి (ఈ వ్యవస్థ బాధ్యతాయుతము).
ఆమె మోపికవాను/మోసికరి/మోపికవానిత/ మోసికతి/ మోపికరాలు (ఆమె బాధ్యతాయుతురాలు).
v. వాను/వాన్ యొక్క భావార్థకము 'వానికము'. ఉదాహరణకు-
తారివాను = యజమానుఁడు; తారివానికము = యాజమాన్యము

3. మంచి/ తటస్థ = 'మారి'
పనిమారి = కార్యశీలుఁడు. కార్యశీల (active). పనియే శీలముగా గలవాఁడు పనిమారి.
i. దీని భావార్ధకము 'పనిమారము: (activity), (చెలికాఁడు చెలికారము వలె), కార్యశీలము.
ii. కావలెనన్నచో దీనికి కూడ స్త్రీలింగ ప్రత్యయమును చేర్చవచ్చును. ఉదాహరణకు- పనిమారిత ఇట్లే-
బాసటమారి = బాసట ఇచ్చుటయే స్వభావముగా గలవాఁడు. (భావార్ధకము: బాసటమారము = సహాయ శీలము)
చదువుమారి = చదువుటయే స్వభావముగా గలవాఁడు (భావార్ధకము చదువుమారము = అధ్యయన శీలము)

4. అలవి/ అల్వి : చేయుటకు శక్యము, సాధ్యము యోగ్యము, అర్హము అని దీని అర్థము.
చదువన్ + అల్వి చదువల్వి = చదువఁదగిన(ది), పఠనీయము (readable)
వినన్ + అల్వి→ వినల్వి = వినఁదగినది, శ్రోతవ్యము (audible)
తినన్ + అల్వి తినల్వి = తినఁదగినది, భక్షణీయము (edible)
ఉండన్ + అల్వి→ ఉండల్వి = ఉండఁదగినది, వసితవ్యము (livable).

5. అరిది/ అర్ది' ప్రత్యయము ఇది 'అలవి' ప్రత్యయమునకు వ్యతిరేకార్థకము.
చదువన్ + ఆర్ది→ చదువరి = చదువఁదగని (ది), అపఠనీయము (unreadable)
వినన్ + ఆర్ది→ విసర్ది = వినఁదగనిది, అశ్రోతవ్యము (inaudible)
తినన్ + ఆర్ది తిసర్ది = తినఁదగనిది, అభక్షణీయము (inedible)
ఉండన్ + ఆర్ది → ఉండర్ది = ఉండఁదగనిది, అవసితవ్యం (unlivable).
