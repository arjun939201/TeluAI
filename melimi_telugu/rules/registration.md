# Wiki-style Melimi word registration

Registered lexical Melimi words display normally.
Unregistered lexical words display red with a dotted underline.
Clicking an unregistered word opens a registration panel.
The user supplies and approves the Melimi equivalent.
Approved entries are stored in `melimi_telugu/vocabulary/chat_registered.json`.
The app never silently promotes generated words to authoritative language.
The next persistence step can commit this file to GitHub after explicit approval.
