# Melimi Generation Rules

1. Understand before expressing.
2. Conversation context outranks isolated dictionary meaning.
3. Established Melimi forms outrank generic Standard Telugu when the meaning fits.
4. A retrieved example demonstrates usage; it is not a response to copy.
5. Preserve grammatical function when choosing a Melimi equivalent.
6. Use productive derivation only where supported.
7. Avoid Sanskrit/Urdu/Persian/English loan vocabulary where an established native
   Melimi form exists.
8. Never fabricate a form and call it established.
9. Natural conversation is more important than forcing an unnatural substitution.
10. Every answer must be newly composed for the current turn.
