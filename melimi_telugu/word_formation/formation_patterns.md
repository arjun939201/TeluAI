# Documented Melimi Formation Patterns

## Initial-letter deletion / remaining-letter formations

- కరఁగు + కల్లు → కరకల్లు
- చిచ్చు + క్రోవి → చిక్రోవి / సిక్రోవి
- ప్రొద్దు + పాఱిక → ప్రొవ్వాటిక / ప్రావాఱిక / ప్రోవాఱిక
- ఉండు + వలతి → ఉన్వలతి
- మోము + తీరు → మోదీరు
- గంగి + నూలు → గన్నూలు
- గంగి + నోలు → గన్నోలు

These are documented formations, not spelling mistakes.

## Reduplication / ఆమ్రేడితం

- చివర చివర → చిట్టచివర / చిటారు
- మిడిమిడి → మిట్టమిడి / మిటారము
- గుడి గుడి → గుడారము
- కడ కడ → కట్టకడ / కటారు
- మఱు + మఱు → మమ్మఱు; mమ్మఱించు / మామణించు; మామఱింపు; మామఱిదం
- తఱచు + తఱచు → తందఱచు → తందరుసు
- సైకము + సైకము → ససైకము
- సలుపు + సలుపు → సంసల్పు
- వంచి + వంచి → వావంచి
- వంచ + వంచ → వావంచ

## Analogy

- ప్రాఁత → ప్రాచీ
- క్రొత్త → క్రోచి
- లోవైనము = గతము
- అలవైనము = ఇతిహాసము

Do not generalize analogy beyond corpus evidence.
