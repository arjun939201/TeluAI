# TeluAI v1.0.4

- Melimi language content is runtime PostgreSQL data instead of repository corpus files.
- Added TXT/MD/JSON/ZIP language-content ingestion with original-document preservation and mapping extraction.
- Owner/admin content can be activated immediately; regular-user submissions remain pending for approval.
- Approved language updates invalidate the root dictionary, lexical registry, retrieval index, firewall cache, and response-cache version.
- Melimi morphology remains root-first and generic rather than using manually maintained derivative lists.
- Simplified `＋ కొత్తగా చేర్చు` to exactly two choices; each opens a separate entry window.
- Updated the release version to 1.0.4.
